The bouncer

Read the rules. Does each packet get in, or is it blocked?

Security groups

One per resource, allow rules only, anything not listed stays out. Stateful, it remembers who it let in.
  • puff-alb-sg: TCP 80 from 0.0.0.0/0
  • puff-api-sg: TCP 8080 from puff-alb-sg
  • puff-db-sg: TCP 5432 from puff-api-sg

Network ACL, public subnets

Whole subnet, lowest number first, first match wins. Stateless, no memory.
  • In 90: DENY all from 203.0.113.0/24
  • In 100: ALLOW TCP 80 from 0.0.0.0/0
  • In *: DENY all
  • Out 100: ALLOW TCP 80 to 0.0.0.0/0
  • Out *: DENY all
Pick Gets in or Blocked.
