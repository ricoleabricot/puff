        EC2 is a hotel room

        Pick the size, check in, check out. Rented in about a minute, paid by the second, someone else fixes the plumbing.

          Four choices to launch one

          • The AMIWhat it boots, like a fresh laptop. We use Amazon Linux 2023, with dnf
          • The instance typeThe room size. A t3.micro is 2 vCPUs and 1 GiB, plenty for the board app
          • The diskWhat storage it gets, and what survives when it dies
          • User dataWhat it does by itself on first boot

            Apps need different rooms

            Family Built for Example
            T (t3, t4g)Short bursts of CPUA small API, the board app
            M (m7i, m7g)A bit of everythingA web app with real traffic
            C (c7i, c7g)Raw CPUVideo encoding, batch jobs
            R (r7i, r7g)Lots of memoryCaches, in-memory analytics
            I (i4i)Very fast local diskDatabases you run yourself
            G, P (g5, p5)GPUsMachine learning inference

            Start small in T or M, measure for a week, then resize. A wrong guess costs five minutes.

                                      Lose the database, and the messages are gone.

                                        What "managed" buys you on RDS

                                        • BackupsA daily snapshot plus every change, kept 1 to 35 days. Rewind to any second
                                        • PatchingUpdates in a maintenance window you choose
                                        • FailoverMulti-AZ keeps a twin in another AZ. The endpoint moves to it in a minute or two
                                        • Storage and monitoringThe disk grows without downtime, metrics land in CloudWatch

                                          Rent the caretaker, or be one

                                          RDS PostgreSQL PostgreSQL on EC2
                                          SetupA form or one CLI commandYou install and lock it down
                                          BackupsBuilt in, rewind to any secondYou script pg_dump and test restores
                                          Surviving a crashTick the Multi-AZ boxYou build replication and failover
                                          ControlNo superuser, limited extensionsFull root, any extension
                                          CostHigher per hourLower per hour, higher in your time

                                          Run it yourself only when you need something RDS can't do.

                                            DynamoDB is a giant coat check

                                            Hand over your ticket, get your coat back instantly. But you can't ask for every red coat.

                                              Pick by how you'll read the data

                                              RDS DynamoDB
                                              Data looks likeTables that reference each otherItems fetched by key
                                              QuestionsAny SQL, even ones you invent laterOnly what your keys allow

                                              An insurer's members, contracts and claims: relational. A "last seen" per phone, millions of times a day: DynamoDB.
