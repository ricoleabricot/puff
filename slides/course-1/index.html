                    Four words people mix up

                    The question The board app on Puff
                    ScalabilityCan it handle more if I add resources?A second API server doubles capacity
                    ElasticityDoes it add and remove resources by itself?2 servers at 8:55, 4 at 9:00, back to 2 at 9:30
                    High availabilityDoes it stay up when something fails, with a short blip?A server dies, traffic moves to the other in seconds
                    Fault toleranceDoes it keep working with zero visible interruption?Two copies always serve, losing one changes nothing

                    Most web apps aim for high availability. Fault tolerance costs more.
